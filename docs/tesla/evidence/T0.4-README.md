## Reproduce

Use the built workspace and Python 3.12 environment. Invoke each process separately:
macOS upstream capture needs inherited file descriptors (`fork`), and running all
process types sequentially inside one interpreter can hang at later native startup.
The harness sets fork and bounds startup at 90 seconds; ordinary replay steps use
upstream timeout handling. No production source changes were made for replay.

```sh
cd /Users/mile/work/tesla-port/replay-baseline
export PYTHONPATH="$PWD:$PWD/opendbc_repo:$PWD/msgq_repo:$PWD/rednose_repo:$PWD/tinygrad_repo"
for proc in card controlsd plannerd selfdrived; do
  /Users/mile/Desktop/mo-op/.venv/bin/python \
    /Users/mile/work/tesla-port/replay-evidence/replay_toyota.py \
    /Users/mile/work/tesla-port/replay-input/toyota-full.rlog.zst \
    "/Users/mile/work/tesla-port/replay-evidence/recheck-baseline-$proc" \
    --process "$proc"
done
```

Repeat with cwd `lean-mici` and a different output prefix. Each invocation repeats
twice internally and exits nonzero for any exception, missing service, insufficient
validity, or hash mismatch. Compare the reference and migrated SHA values in each
report. Initial harness failures are preserved in baseline/, baseline-v2/, baseline-v3/
for diagnosis; they are not acceptance artifacts.

Scope: a single real Prius segment with recorded inputs fed separately to each
process. This proves deterministic software output equivalence for this fixture;
it does not establish coupled live-process timing, all Toyota models, or vehicle
acceptance. Hardware and Tesla driving behavior require their independent gates.
