# Authentic Tesla CAN loop (offline export)

`tesla_can_loop.xz` matches the existing Sienna Jungle fixture format:
XZ-compressed pickle protocol4, `list[list[(address, payload_bytes, bus)]]`.
It contains **199730 unchanged received CAN frames** from the public ModelY route
`2c912ca5de3b1ee9|0000025d--6eb6bcbca4--4`, with 5999 batches consumed at100Hz.
The recorded span is59.989696088seconds; empty10ms buckets are retained.

Fixture SHA256: `076005e6a33d461c50da3bfc04b708b266fa4cc352862620a9e3f3cb53e97b5f`.
Original rlog SHA256: `ca3bfc37b118f0e1987c2177b77b7446d44fbc7806cc5fae71c2ed79d4776fff`.
See `tesla_can_loop.provenance.json` for URL, byte counts, platforms, timestamps,
bus/address counts, excluded returned/virtual frames, and validation assertions.

Recorded ignition: all600 panda observations have ignitionCan=true and
ignitionLine=false. All1200 bus0/0x221 messages have vehiclePowerState=3(DRIVE)
and valid Tesla checksum. This is an ignition-on recorded segment, **not an
ignition-cycle recording**. Its finite loop boundary restarts recorded counters;
it must not be described as continuous live traffic or actual hardware acceptance.

Only physical receive buses0/1/2 are exported. This route has frames only on0/2.
Returned/virtual source IDs128/130/192 are excluded and explicitly counted.
No payload/address/bus rewrites, no synthesized frames, no sendcan events, and
no active vehicle/Jungle actions were performed. The shell's `--check` exits before
loading Panda/Jungle or accessing USB; its metadata output is in jungle-check.json.

Validation completed:

1. Existing Sienna fixture parsed and pickle/lzma roundtripped before generator authoring.
2. Source zstd end-of-frame and no trailing data checked; Cap'n Proto parsing warnings fatal.
3. Tesla carParams platform, monotonic CAN timestamps, classic CAN payload sizes checked.
4. Flattened exported frame sequence asserted exactly equal to selected source sequence.
5. Fixture file decompressed/unpickled back to identical batches.
6. Two independent generator invocations yielded byte-identical fixtures (`cmp` exit0).
7. Existing `jungle_replay.sh --check` accepted the fixture and reported the expected hash.
